## Project Overview

During this consulting engagement I worked through four client engagements based on realistic business scenarios involving MedTech Industries.

The work included identifying control deficiencies, evaluating IT processes against industry best practices, documenting audit evidence, testing IT General Controls, and communicating findings through executive-level deliverables.

## Project Structure

### Task 1 – Risk Assessment

**Objective**

Perform a Procure-to-Pay (P2P) risk assessment by reviewing business processes, identifying missing controls, evaluating associated risks, and documenting recommendations.

**Deliverables**

- Risk Assessment Instructions
- Risk Assessment Deliverable

---

### Task 2 – SDLC Walkthrough

**Objective**

Conduct an SDLC walkthrough by identifying process gaps, asking appropriate audit questions, and evaluating software development governance against industry best practices.

**Deliverables**

- SDLC Walkthrough Instructions
- Completed SDLC Walkthrough

---

### Task 3 – IT General Controls (ITGC) Testing

**Objective**

Evaluate the design and operating effectiveness of change management controls using client evidence and supporting documentation.

Activities included:

- Testing standard and emergency change management controls
- Evaluating Segregation of Duties (SoD)
- Reviewing change approvals
- Inspecting implementation evidence
- Assessing User Acceptance Testing (UAT)
- Identifying control exceptions
- Documenting audit conclusions

**Supporting Evidence Reviewed**

- Client engagement email
- Walkthrough notes
- Standard Change Request
- Emergency Change Request
- Developer / Implementer User List

**Deliverables**

- ITGC Testing Instructions
- Completed ITGC Testing Workbook

---

### Task 4 – Controls Testing Summary

**Objective**

Prepare an executive-level presentation summarizing control deficiencies, business impact, and recommended remediation actions for client leadership.

**Deliverables**

- Controls Testing Instructions
- Executive Summary Presentation
