PwC Cybersecurity Consulting Case Study (GRC)
Overview

This repository documents my completion of PwC's Cyber Security Consulting Virtual Experience through Forage. The simulation focused on Governance, Risk, and Compliance (GRC), IT General Controls (ITGC), Software Development Lifecycle (SDLC) governance, and security consulting activities performed during enterprise system implementations.

Throughout the engagement, I analyzed business processes, identified internal control weaknesses, performed ITGC testing, evaluated SDLC governance against leading practices, and communicated findings through executive-level deliverables.

This project reflects the type of work performed by GRC Analysts, IT Auditors, IT Risk Consultants, and Security Compliance professionals supporting SOX and enterprise governance initiatives.

Project Deliverables
Task 1 – Risk Assessment

Performed a risk assessment of MedTech Industries' Procure-to-Pay (P2P) process by reviewing business process documentation and identifying internal control gaps, IT control weaknesses, and follow-up questions for management.

Deliverables

Risk Assessment Summary
Control Gap Analysis
Management Questions
Task 2 – SDLC Walkthrough

Reviewed MedTech's SDLC process against NIST leading practices and participated in a simulated client walkthrough to identify process gaps and recommend improvements.

Key areas evaluated included:

SDLC governance
System testing
Design reviews
Configuration management
Client interview techniques
Task 3 – IT General Controls Testing

Performed Test of Design (ToD) and Operating Effectiveness (OE) testing for Change Management IT General Controls.

Evaluated evidence supporting:

Emergency Change Management
Segregation of Duties
User Acceptance Testing
Change Approvals
Production Deployment Controls

Documented identified exceptions and provided remediation recommendations.

Task 4 – Executive Controls Summary

Prepared an executive-level management presentation summarizing identified control deficiencies and recommended remediation activities for senior leadership.

The presentation focused on:

Emergency Change Management
Segregation of Duties
SDLC Design Reviews
Key Findings

The assessment identified several opportunities to strengthen MedTech's control environment, including:

Missing evidence of required post-implementation approvals for emergency changes
Segregation of Duties conflict where one user possessed both developer and production implementation access
Lack of formal SDLC design reviews prior to production deployment

Recommendations included strengthening approval workflows, implementing periodic access reviews, and formalizing SDLC governance practices.
